GitHub Pages 上传说明

1. 打开仓库：https://github.com/huansong-uw/huansong-uw.github.io
2. 点击 Add file -> Upload files。
3. 将本文件夹中的全部内容上传到仓库根目录：
   - index.html
   - Huan_Song_CV_2026.docx
   - images 文件夹（其中包含 hero.png）
4. 点击 Commit changes。
5. 等待约 1–3 分钟后刷新：https://huansong-uw.github.io/

注意：不要只上传压缩包。请先解压，再上传里面的文件和文件夹。
